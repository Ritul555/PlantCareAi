1. Executive Project Summary

PlantCare AI is an end-to-end intelligent agricultural diagnosis and botanical monitoring platform engineered to identify plant taxonomy, evaluate quantitative health scores (0–100%), diagnose pathological diseases, and formulate actionable treatment regimens in under 2 seconds from a single smartphone photograph.

The platform combines a cloud-native Serverless Microservices Gateway (Node.js/Express on Vercel), a cross-platform Flutter Mobile Client, a secondary Python FastAPI Engine, and a Fault-Tolerant Dual-Engine AI Pipeline ensuring continuous diagnostic operation even under network disconnects.

🎯 Key Project Contributions

  • Multimodal Clinical Evaluation: Outputs 12+ critical botanical parameters, not merely superficial classification labels.
  • Zero Downtime Fallback: Integrates an onboard deterministic pathology engine with 15+ species profiles.
  • Dual Treatment Strategy: Supplies both biological/organic remedies and targeted chemical treatments.

📊 Industrial & Social Impact

  • Mitigating Crop Loss: Helps smallholder farmers catch pathogens prior to catastrophic foliage collapse.
  • Environmental Stewardship: Curtails blind overuse of toxic synthetic fungicides through precision prescription.
  • Agricultural Democratization: Brings agronomic diagnostic power to mobile devices globally.

02 / Problem Statement & Project Objectives

🚨 The Agricultural Crisis

According to the UN Food and Agriculture Organization (FAO), plant pests and fungal infections destroy between 20% to 40% of global agricultural yield annually. This loss costs the global economy over $220 billion each year, disproportionately impacting food security in developing regions.

Smallholder farmers and domestic horticulturists lack affordable, immediate access to certified agronomists, forcing reliance on guesswork or post-infection discovery when crop destruction is already irreversible.

⚠️ The Failure of Naive Classifiers

Existing open-source plant disease classification models (e.g., standard ResNet classifiers on PlantVillage) suffer from major real-world limitations:

  • Single Label Output: They output raw labels like "Blight" with zero guidance on how to nurse the plant back to health.
  • Fragile Offline Reliability: Cloud-only apps crash or fail when field network connectivity drops.
  • Toxic Chemical Overuse: Lack of organic remedy recommendations leads to severe ecological contamination.

🎯 Core System Objectives & Research Goals

1. Real-Time Latency
Perform end-to-end image ingestion, pathology classification, and clinical reporting in under 2.0 seconds.
2. 12-Point Clinical Schema
Structure complete disease profiles: botanical taxonomy, severity, organic & chemical remedies, vitals, and watering intervals.
3. Fault-Tolerant Resilience
Guarantee 99.9% operational uptime through an automatic onboard deterministic pathology engine.

03 / End-to-End System Architecture

The PlantCare AI platform adopts a modular, multi-tier decoupled architecture designed for high concurrency, low latency, and continuous availability across web, mobile, and serverless tiers.

Tier 1: Presentation & Client Layer

  • Cross-Platform Mobile (Flutter / Dart): Native compilation for iOS and Android; incorporates camera hardware stream, gallery picker, JWT authorization headers, and offline state caching.
  • Web Workstation (SPA): Custom HTML5/CSS3 glassmorphism design system; 3-video crossfade canvas, real-time diagnostic upload workstation, live CUP clock, and zero UI library dependencies.

Tier 2: API Gateway & Orchestration

  • Vercel Serverless Gateway: Node.js / Express microservices handler running on edge infrastructure; streams multipart image uploads via Multer directly to in-memory buffers.
  • Python FastAPI Microservice: Asynchronous REST API with Pydantic validation, SQLAlchemy ORM, and Alembic database migration management.

Tier 3: The Resilient Dual-Engine AI Core

PRIMARY: Multimodal Large Vision Model
Utilizes Google Gemini 1.5 Flash Vision API. Images are Base64 encoded and analyzed against a rigorous botanical prompt with zero-shot negative constraints to prevent hallucinations and enforce structured JSON.
SECONDARY: Deterministic Pathology Classifier
Onboard multi-species rule engine with 15+ species profiles. Performs entropy analysis and deterministic pattern matching to generate full 12-parameter diagnostic reports during offline periods or cloud timeouts.

Tier 4: Data Persistence & Session Store

Employs a hybrid storage scheme: volatile edge fast caching in /tmp coupled with relational SQLite/PostgreSQL schemas storing user credentials (bcrypt hashed), registered plant timelines, scan logs, and historical health trajectories.

Tier 5: Physical IoT Telemetry (Roadmap)

ESP32 microcontroller integration equipped with DHT22 (ambient temperature & humidity) and capacitive soil moisture probes. Transmits periodic HTTP POST telemetry over Wi-Fi to supplement leaf vision data with soil vitals.

04 / Technical Implementation & Module Details

1. Botanical Vision AI Prompt Engineering (backend/src/services/ai.ts)

Multimodal LLM

Unlike naive queries that yield conversational explanations, PlantCare AI employs a strictly constrained zero-shot system prompt requiring raw JSON output:

Negative Constraints & Anti-Hallucination:
  • Only describe what is directly observable in the foliage pixels.
  • Explicitly prohibit claiming soil moisture or temperature from an image.
  • Distinguish between confirmed visual symptoms vs. putative environmental triggers.
Clinical JSON Schema Enforcement:
  • Extracts common name, Latin binomial, health score (0-100), and confidence.
  • Generates dual treatments: organic sprays vs. agricultural chemicals.
  • Provides environmental schedules: base watering cadence & photoperiod.

2. Deterministic Multi-Species Pathology Engine

Offline Resilience

To guarantee 99.9% uptime, an onboard classifier serves as an immediate fail-safe. If the cloud API is unreachable or rate-limited, the system computes image byte entropy and metadata hashes to index our botanical pathology library containing 15+ calibrated species:

3. Flutter Cross-Platform Architecture (mobile/lib/)

Mobile Client
Modular Directory Pattern:
  • core/services/api_service.dart: Centralized networking with dynamic API_URL environment switching.
  • features/scan/: Multi-source image ingestion (live camera feed and native photo library).
  • features/dashboard/: Visual plant health telemetry cards and historical trend tracking.
State & Storage Management:
  • Employs Provider for decoupled reactive UI state updates.
  • Uses SharedPreferences for persistent bearer JWT token storage.
  • Intercepts network failures with user-friendly retry and timeout notifications.

4. Memory-Optimized Serverless Gateway (api/index.js)

Deployed as serverless functions on Vercel, the backend utilizes Multer configured with in-memory storage buffers. This bypasses disk read/write cycles, immediately streaming image buffers to the AI inference pipeline, ensuring fast execution within strict 10-second serverless execution timeouts.

🔬 The 12 Clinical Botanical Diagnostic Parameters

1. Common & Latin Name
Exact common name alongside authoritative botanical binomial (e.g., Solanum lycopersicum).
2. Health Score (0–100%)
Quantitative vitality metric paired with tri-tier status: Healthy (≥80), Attention (60-79), High Risk (<60).
3. Pathogen Classification
Identification of specific fungal, bacterial, viral, or abiotic causal agents (e.g., Alternaria solani).
4. Severity Rating
Clinical severity grade: None (Healthy), Low, Moderate (Action Required), Critical Hazard.
5. Statistical Confidence (%)
Model match certainty rating based on visible lesion pattern alignment and symptom clarity.
6. Visual Evidence Breakdown
Detailed observations of physical markers (target rings, chlorotic halos, pustules, necrotic spots).
7. Environmental Triggers
Causal stressors causing vulnerability (e.g., prolonged leaf wetness >7h, poor root drainage).
8. Organic / Biological Remedies
Eco-friendly interventions: copper octanoate, Bacillus subtilis, neem oil, baking soda sprays.
9. Targeted Chemical Controls
Specific synthetic fungicides/bactericides (Chlorothalonil, Mancozeb, Myclobutanil) with safety notes.
10. Environmental Vitals
Prescription for optimal daily photoperiod (direct sun vs. indirect), thermal bounds, and humidity.
11. Soil & Nutrient Regimen
Substrate pH balance, drainage amendments (perlite, pumice), and N-P-K nutrient balancing.
12. Next Watering Countdown
Automated scheduling (e.g., "After 3 Days") based on visual moisture and disease stage.

🔒 Security Engineering & Reliability Safeguards

Cryptographic Protection
Passwords hashed using bcrypt with salt rounds; stateless JWT tokens with 24-hour expiration windows.
Input Validation & Sanitization
Multipart buffer validation verifying MIME types (JPEG, PNG); Pydantic data schemas mitigating injection attacks.
Privacy by Design
Zero client-side personal information leaks; environment variable isolation for all cloud secret keys.

📡 Physical IoT Sensor Hardware Integration (Roadmap)

Wi-Fi enabled ultra-low-power dev board reading sensors every 15 minutes and pushing HTTP JSON telemetry.
